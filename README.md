# 一張明信片，去旅行｜Postcard Journey

第九週「換你當老闆：Agentic Work」網站作業。把自己的旅行照片放進可愛的明信片邊框，並透過 `AGENTS.md` 讓 AI 能遵守一致的規則持續新增邊框樣式。

## 如何使用

1. 解壓縮後，雙擊 `index.html`（Windows 可能只顯示為 `index`）。
2. 上傳自己的 **JPG、PNG 或 WebP** 照片，最多 15 MB。手機 HEIC 照片建議先轉 JPG。
3. 從 **12 種邊框** 選一款，輸入旅行地點、可選填國家與心情文字。
4. 即時預覽後，點「生成我的旅行明信片」，再按「下載明信片 PNG」即可將完成品存進電腦。
5. 也可按「收進收藏牆」，在本機瀏覽器收藏、搜尋、依國家分類、加愛心或刪除卡片。

**隱私與儲存**：照片不會上傳伺服器；下載檔案在自己的裝置；收藏牆只存在當前瀏覽器的 `localStorage`，最多 20 張，容量不足時請先下載，清除瀏覽器資料可能遺失；不同裝置不會自動同步。

**本網站不是 AI 即時生圖**：使用者自行上傳照片並套入邊框，不會自動生成某地點的真實照片。

## 專案結構

- `index.html`：主要頁面（製作所、收藏牆）
- `styles.css`：手帳風 UI 與手機版面
- `frames.js`：12 款邊框的標準化清單，AI 未來可依規則新增
- `app.js`：Canvas 繪製、照片上傳、PNG 下載、本機收藏與篩選
- `AGENTS.md`：AI 工作手冊，說明結構、風格、固定格式、修改規則與驗收清單

## 如何依 AGENTS.md 擴充

未來可以對具有檔案修改能力的 AI 說：

> 請先讀 `AGENTS.md`，依照上面的規則，提出新增「春日花園」明信片邊框的規劃。先提供配色、排版及預期效果，等我確認後才修改。只改必要檔案，完成後照檢查清單驗證。

AI 確認後，只要在 `frames.js` 的 `window.POSTCARD_FRAMES` 陣列新增一筆符合規格的物件，網站就會自動多出新的邊框選項，不必再重做首頁、下載或收藏功能。

### 可用於課堂展示的擴充例子

初始相框中「夜空小旅行」（`starlight`）以 `layout: 'minimal'`、`motif: 'stars'`、紫色系配色實作。它使用同一套 `frames.js` 物件格式，示範新增相框不需要新頁面或個別的下載程式。正式繳交時，仍建議再實測新增第十三款邊框，截圖保留修改過程與成果。

## GitHub Pages 發布

1. 在 GitHub 建立公開 Repository，例如 `postcard-journey`。
2. 上傳此資料夾內的所有檔案（包含 `AGENTS.md`、`frames.js`）。
3. GitHub Repository → **Settings** → **Pages** → **Build and deployment** → Deploy from a branch，選 `main` 與 `/(root)`，儲存。
4. 發布完成後，開啟 GitHub Pages 提供的公開網址，再測試上傳照片、切換邊框與下載功能。

注意：GitHub Pages 不會儲存訪客上傳的照片；自製明信片不會自動同步到 GitHub。AI 更新 Repo 需要另行授權並取得使用者確認。

## V4 更新：12 張真實景點照片範例

- 新增 `examples.js`，含 12 張世界旅遊範例：富士山、巴黎鐵塔、自由女神像、九份老街、阿里山、韓國城山日出峰、京都伏見稻荷大社、羅馬競技場、雪梨歌劇院、馬丘比丘、泰姬瑪哈陵、聖托里尼。
- 每張指定不同的 `frames.js` 邊框，搭配手帳文字、經查證的介紹、旅行小知識與來源。點選「看介紹」能查看完整資料、照片作者與授權。
- 範例和自行上傳的作品會一起顯示在收藏牆，國家篩選、搜尋、愛心最愛皆支援；預設的景點照片沒有寫入瀏覽器儲存額度，使用者自製的明信片仍保留原本的保存機制。
- 照片來源是 Wikimedia Commons 授權的真實景點攝影，網站**需要網路才能顯示照片**（首次開啟本機 `index.html` 時請確認電腦有網路）；照片與授權頁網址收錄在 `examples.js` 以及網站詳細介紹視窗。圖片不在 ZIP 中，避免來源／授權不明的素材被誤用；如果圖片斷線，網站仍可查看景點介紹與邊框設計。
- 不需 Cloudflare、AI 圖片服務、API key 或付費方案。上傳自己的照片由瀏覽器處理，不會送去網站伺服器。
- 如需另行下載或轉載範例照片，請依每張圖片頁所列授權處理。自製作品的上傳照片應使用自己的或已取得授權的素材。

完整圖片授權與地標資料來源請參考 `PHOTO_CREDITS.md`。
